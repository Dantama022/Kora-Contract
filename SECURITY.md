| Version | Supported |
|---------|-----------|

## Reporting a Vulnerability

**Do not open a public GitHub issue for security vulnerabilities.**

### Submission

**GitHub Security Advisory:** [OpenLedger-Foundation/Kora-Contract Security Advisories](https://github.com/OpenLedger-Foundation/Kora-Contract/security/advisories/new)

**Email:** security@openledger.info / security@kora.finance

If private vulnerability reporting is undergoing configuration or unavailable on GitHub, security researchers can contact the core security team directly via GitHub security contacts or email security@openledger.info.

**Required Information:**
- Description of the vulnerability
- Steps to reproduce (proof-of-concept code preferred)
- Potential impact and severity assessment
- Affected contract(s) and function(s)
- Suggested fix (optional)

### Response SLA

| Severity | Acknowledgment | Patch Timeline |
|----------|---------------|----------------|
| **Critical** | 4 hours | 48 hours |
| **High** | 24 hours | 7 days |
| **Medium** | 72 hours | 30 days |
| **Low** | 1 week | Best effort |

### Bug Bounty Program

We offer rewards for valid vulnerability reports:
- **Critical:** $10,000 - $50,000 USD
- **High:** $2,000 - $10,000 USD
- **Medium:** $500 - $2,000 USD
- **Low:** $100 - $500 USD

See **[docs/BUG_BOUNTY_OPERATIONS.md](docs/BUG_BOUNTY_OPERATIONS.md)** for full program details, scope, and responsible disclosure policy.
